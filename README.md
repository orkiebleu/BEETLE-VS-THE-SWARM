# Beetle vs. the Swarm 🪲

A vaporwave bug-world horde-survival game (Vampire Survivors-like) with **local co-op** — built for the web in vanilla JavaScript + HTML5 Canvas. No build step, no dependencies.

**Play it:** just open `index.html` in a browser (or play at the GitHub Pages link above).

## The game

You are a beetle. The swarm is endless. Survive.

- **P1:** teal rhinoceros beetle — WASD / gamepad 1 / touch
- **P2:** stag beetle in magenta — arrow keys / gamepad 2
- Independent leveling, shared run timer, camera follows the midpoint, soft co-op leash, 15-second revive at your partner
- 10 bug-themed weapons with evolutions (Mandible Slash, Acid Spit, Stinkbug Blast, Pheromone Cloud, Widow's Web, Grub Pack, Elytra Storm…), bug passives (Chitin Plating, Compound Eyes, Royal Jelly…), 3 stages (Leaf Litter, The Compost Heap, Under the Bark), bosses (Praying Mantis, Spider Queen), achievements, and a synthesized synthwave soundtrack
